# Asset Creation Templates - Quick Start

## ICON - Template Design

**What to create:**
- App icon that represents iKHWEZI
- Size: 512×512 pixels PNG
- Save to: `assets/icon/icon.png`

**Quick Design on Canva (10 minutes):**

1. Go to: https://www.canva.com
2. Search: "App Icon"
3. Select 512×512 template
4. Design tips:
   - Use purple, blue, or cosmic colors
   - Add "i" or circle logo
   - Make it bold and recognizable
   - No text inside (optional small text OK)
   - Centered design
5. Download as PNG

**Example Text:**
- Just use "i" for iKHWEZI
- Or use cosmic theme: stars, moon, waves
- Colors: #8B5FFF (purple), #00D4FF (cyan), #000B1E (dark blue)

## FEATURE GRAPHIC - Template Design

**What to create:**
- Promotional banner for app store
- Size: 1024×500 pixels PNG
- Save to: `assets/feature_graphic/feature.png`

**Quick Design on Canva (15 minutes):**

1. Go to: https://www.canva.com
2. Click: "Create a design"
3. Enter size: 1024x500
4. Design:
   - Background: Cosmic gradient (purple to blue)
   - Left side: iKHWEZI logo/text
   - Center: Tagline "Stream the night. Shine the signal."
   - Right side: App features or screenshots
5. Download as PNG

**Design Elements:**
- Bold, eye-catching colors
- Your app logo/name
- Key features icons
- Call to action
- No blurry text

## File Checklist

Before uploading to Google Play, verify:

- [ ] **Icon**
  - File: `assets/icon/icon.png`
  - Size: 512×512 pixels
  - Format: PNG
  - Quality: Clear, no compression artifacts

- [ ] **Screenshots** (4-8 total)
  - Folder: `assets/screenshots/`
  - Size each: 1080×1920 pixels
  - Format: PNG or JPG
  - Named: `screenshot_1.png`, `screenshot_2.png`, etc.
  - Quality: High resolution, no blur

- [ ] **Feature Graphic**
  - File: `assets/feature_graphic/feature.png`
  - Size: 1024×500 pixels
  - Format: PNG
  - Quality: Professional looking
