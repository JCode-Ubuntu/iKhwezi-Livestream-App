# Creating Assets for Google Play Store

## Asset 1: App Icon (512×512 PNG)

### What is it?
- Your app's icon that appears on home screen
- Most important branding element
- Must be recognizable at small sizes

### How to Create:

**Option A: Canva (Easiest - Free)**
1. Go to https://www.canva.com
2. Search: "App Icon 512x512"
3. Design using iKHWEZI branding:
   - Colors: Purple/Blue (cosmic theme)
   - Text: "iKHWEZI" or just logo
   - Style: Modern, bold, clean
4. Export as PNG
5. Save to: `assets/icon/icon.png`

**Option B: AI Image Generator (Free)**
1. Go to https://www.midjourney.com or https://www.leonardo.ai
2. Prompt: "App icon for iKHWEZI livestream app, cosmic purple blue theme, 512x512, app store quality"
3. Generate and download
4. Resize to 512×512 if needed (use Photoshop, GIMP, or online tool)
5. Save as PNG

**Option C: Photoshop/GIMP (Professional)**
1. Create 512×512 canvas
2. Design using iKHWEZI colors and logo
3. Export as PNG

### Tips:
- No text inside icon (or minimal text)
- Make it work at 192×192 (what it looks like on phone home screen)
- Avoid gradients that are too complex
- Use solid or simple pattern background
- Keep 8px padding from edge

## Asset 2: Screenshots (1080×1920 PNG) - 4-8 Images

### What is it?
- Photos showing your app in action
- Users see these before downloading
- Most important for conversion

### Screenshots to Create:

**Screenshot 1: Home Feed**
- Show main feed with videos
- Include title: "Stream Endless Content"

**Screenshot 2: Live Streaming**
- Show live stream in progress
- Include title: "Go Live Instantly"

**Screenshot 3: Video Creation**
- Show video recording/upload interface
- Include title: "Create & Share"

**Screenshot 4: User Interaction**
- Show comments, reactions, or profile
- Include title: "Connect with Community"

### How to Capture Screenshots:

**Option A: Android Emulator (Best for Consistent Quality)**
1. Download Android Studio: https://developer.android.com/studio
2. Create Android Emulator (Pixel 5 - 1080×1920)
3. Launch your app
4. Press **Ctrl+S** (Windows) or **Cmd+S** (Mac) to screenshot
5. Save to `assets/screenshots/`

**Option B: Real Android Phone**
1. Install your app
2. Navigate to each feature
3. Press Volume Down + Power to screenshot
4. Copy to computer
5. Resize to 1080×1920 if needed
6. Save to `assets/screenshots/`

**Option C: Add Text Overlays**
1. Screenshot in app
2. Open in Canva or Photoshop
3. Add text overlay explaining feature
4. Save as PNG

### Naming:
```
screenshot_1_home_feed.png
screenshot_2_live_streaming.png
screenshot_3_video_creation.png
screenshot_4_community.png
```

### Tips:
- Use real app content (not mockups)
- Show at least 4 different features
- Text overlays: "Stream Endless Content", "Go Live", "Create & Share", etc.
- Consistent branding/colors
- High resolution (1080×1920 exactly)
- Portrait orientation (vertical)

## Asset 3: Feature Graphic (1024×500 PNG)

### What is it?
- Large promotional banner
- Shows up in featured apps section
- First visual impression

### How to Create:

**Option A: Canva (Easiest)**
1. Go to https://www.canva.com
2. Create custom size: 1024×500
3. Design:
   - Left half: iKHWEZI logo/branding
   - Right half: Key features or app preview
   - Center: Tagline "Stream the night. Shine the signal."
4. Export as PNG
5. Save to: `assets/feature_graphic/feature.png`

**Option B: AI Generator**
1. Prompt: "App promotional banner 1024x500, iKHWEZI livestream app, cosmic purple theme, text: 'Stream the night. Shine the signal.'"
2. Generate at https://www.midjourney.com
3. Resize/crop to exact 1024×500
4. Save as PNG

**Option C: Photoshop**
1. Create 1024×500 canvas
2. Add background (cosmic purple/blue gradient)
3. Add logo left side
4. Add tagline center/bottom
5. Add app features (video camera, live icon, etc.) right side
6. Export as PNG

### Design Inspiration:
- TikTok, Instagram, YouTube app banners
- Modern, colorful, eye-catching
- Include app name prominently
- Show diversity (different people/cultures)

### Tips:
- Size MUST be 1024×500 pixels exactly
- High contrast text (readable at small sizes)
- Include app name/logo
- No excess padding
- PNG format
- File size < 5MB
