FOLDER: assets/screenshots/

WHAT TO PUT HERE: Phone screenshots showing app features

SPECIFICATIONS PER SCREENSHOT:
- Size: 1080×1920 pixels (9:16 aspect ratio)
- Format: PNG or JPG
- Quantity: 2-8 images (Google Play recommends 4+)
- Orientation: Portrait (for phones)

NAMING CONVENTION:
- screenshot_1.png
- screenshot_2.png
- screenshot_3.png
- etc.

RECOMMENDED SCREENSHOTS (Show These):
1. Home feed view (main content)
2. Live streaming interface
3. Video creation/upload
4. User profile
5. Comments/interactions
6. Stories feature
7. Messages/DMs
8. Settings/admin panel

TIPS FOR GOOD SCREENSHOTS:
- Clear, high-resolution
- Include text labels explaining features
- Show app UI clearly (good lighting)
- Use real app usage, not mockups
- Highlight unique features
- Make them visually appealing
- Consistent branding/colors

HOW TO CAPTURE:
- Android device or emulator: Screenshot key
- Use Android Studio emulator for consistent quality
- Or use real device with screen recording + screenshot

HOW TO UPLOAD:
1. Google Play Console → App listing → Manage screenshots
2. Select "Phone" category
3. Upload your 1080×1920 images
4. You can add text/captions to screenshots

FILE LOCATION: Place all .png or .jpg files in this folder
