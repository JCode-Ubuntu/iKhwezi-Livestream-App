# iKHWEZI V3 - Instagram-Inspired Creator Platform

## 🎬 Features

✅ **Instagram-Style Feed**
- Post creation & sharing
- Like & comment system
- Stories (24-hour temporary posts)
- User profiles

✅ **Livestream (Admin Only)**
- Start/stop broadcasts from admin panel
- Real-time viewer count
- RTMP stream integration
- Stream statistics

✅ **Admin Dashboard**
- Livestream control
- User management
- Platform analytics
- Content moderation

✅ **Modern Dark UI**
- Instagram-inspired design
- Black theme with accent colors
- Smooth animations
- Mobile responsive

## 🚀 Quick Start

```bash
npm install
npm run dev      # Development
npm run build    # Production build
```

## 📱 Routes

- `/` - Main Feed (Instagram-style)
- `/admin` - Admin Dashboard
- `/admin/livestream` - Livestream Control Panel

## 🔑 Admin Access

Visit `/admin` to manage:
- Start/stop livestreams
- View real-time statistics
- Manage users & content
- Configure streams
